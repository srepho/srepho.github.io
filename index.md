## Recent Projects (2024-2026)

### AI Agents & Frameworks

#### [Dory - AI Agent Framework Comparison](https://github.com/srepho/dory)
Comprehensive evaluation of 11 AI agent frameworks for insurance claims processing. Includes tutorials, demos, and integration with DSPy and MLFlow.

#### [Australian Insurance Obligations Extractor](https://github.com/srepho/australian-insurance-obligations)
LLM-powered system for extracting and validating insurance compliance obligations from Australian legislation. Extracted 343 obligations from 16 legislative documents.

#### [PromptOpt](https://github.com/srepho/promptopt)
Enterprise prompt optimization framework combining DSPy and GRPO approaches for systematic prompt engineering.

### Python Packages

#### [Allyanonimiser](https://github.com/srepho/Allyanonimiser)
A Python package for removing PII and related sensitive fields from free text. Designed for data privacy compliance in production environments.

#### [Freamon](https://github.com/srepho/freamon)
A package to make data science projects on tabular data easier. Named after the great character from The Wire played by Clarke Peters.

#### [Meno](https://github.com/srepho/meno)
Topic modelling package for free text analysis, designed especially for the insurance domain.

#### [Heraclitus](https://github.com/srepho/heraclitus)
A library for making Process Mining accessible to new users. Works well with PM4PY while adding new features.

### LLM Research

#### [AULegalLLM](https://github.com/srepho/AULegalLLM)
Finetuning large language models on Australian legal data for domain-specific applications.

#### [Data Shootout: LLMs vs GBMs](https://github.com/srepho/datashootout)
An investigation comparing LLMs versus Gradient Boosting Machines for tabular datasets containing free text fields.

#### [Evolutionary Selection Economics](https://github.com/srepho/evolutionary-selection-economics)
Selection as a search algorithm: exploring evolutionary economics and the conditions for group selection.
